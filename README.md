# MIRA

**Management, Infrastructure, Resources & Automation**

MIRA is a modular, self-hosted platform for managing,
monitoring and automating local AI infrastructure.

## Planned Features

- Dashboard for system status and quick actions
- AI server monitoring and power management
- Energy monitoring with Shelly Plug
- Management of AI agents
- Local GGUF model inventory and direct downloads
- Modular configuration interface
- Secure web-based access

## Architecture

MIRA is designed as a modular monolith.

- `backend/` — Core services and functional modules
- `frontend/` — Web user interface
- `docs/mockups/` — Approved UI design references
- `deploy/` — Deployment and container configuration
- `tests/` — Automated tests
